# Code of Conduct

## Our pledge

Be decent. We are all here to make agent ecosystems safer.

## Our standards

- Assume good faith, especially from newcomers.
- Critique code, not people.
- No harassment, personal attacks, or exclusionary language.

## Enforcement

Report problems to the maintainers via GitHub. Maintainers may remove
comments and ban contributors who repeatedly break these rules.

This code of conduct applies to everyone participating in this project.
