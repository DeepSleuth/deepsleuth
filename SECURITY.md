# Security Policy

## Supported versions

Only the latest release line receives security fixes.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting on this repository
(Report a vulnerability under the Security tab). Please do not open a
public issue for anything security-sensitive.

Include reproduction steps where possible. deepsleuth is itself a
security scanner, so findings about its own analysis (missed detections,
bypasses) are especially welcome — describe the target server shape and
the finding (or absence) you observed.

We aim to respond within a few business days.
